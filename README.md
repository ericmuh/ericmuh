## What This Site Includes

- Responsive modern portfolio layout (desktop, tablet, mobile)
- Interactive sticky navigation with mobile menu and active section highlighting
- Accessible smooth scrolling, focus states, and reduced-motion support
- Light/dark theme toggle with saved user preference
- Sections for hero, about, skills, professional profile, selected projects, and contact
- Working contact pathways (email, LinkedIn, GitHub)
- Downloadable contact card (`public/eric-muhwezi-contact.vcf`)

## Local Development

```bash
# Clone the repository
git clone https://github.com/ericmuh/ericmuh.git
cd ericmuh

# Install dependencies
npm install

# Start development server
npm run dev

# Lint
npm run lint

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
